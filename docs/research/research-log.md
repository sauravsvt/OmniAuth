# Research Log

Source-backed notes for OmniAuth decisions, brainstorms, and learning. Required by `.cursor/rules/research-freshness.mdc`, `.cursor/rules/brainstorming.mdc`, and `.cursor/rules/decision-research.md`.

## Format

Each entry uses the structure:

```markdown
## YYYY-MM-DD Title

### Context

What triggered this entry (decision, brainstorm, audit prep, paper claim, sibling sync).

### Sources

- Citation key (BibTeX in `references.bib`), URL, date checked.

### Findings

What the sources actually say, distinguished from interpretation.

### Action

What was done, what was deferred, what is now an open question.

### Sibling Impact

Whether MyPassword should mirror this finding.
```
